### ✅ 해결 방법

- 체크 배열을 생성하는데 그 값은 1로 한다.
- 입력받은 28개의 값은 인덱스와 동일하게 맞춰주기 위해 1을 빼준다.
- 체크배열에서 1의 값이 있다면 과제를 제출하지 않은 출석번호를 의미이다.
