## 💡 오늘의 핵심 인사이트


- 단일 연결 리스트(singly linked list)는 **역방향 탐색이 불가능**하므로, 값을 배열에 복사한 뒤 슬라이싱으로 비교하는 방식이 가장 간결하다.
- 문자열 팰린드롬(125번)과 연결 리스트 팰린드롬(234번)은 **자료구조만 다를 뿐 해결 패턴이 동일**하다: "간결 풀이 O(N) 공간 ↔ 최적화 풀이 O(1) 공간".
- LeetCode의 **Follow-up 요구사항(O(N) time, O(1) space)** 은 면접 단골 질문. 연결 리스트 문제에서는 특히 공간 최적화 버전을 반드시 준비해야 한다.
- O(1) 공간 최적화의 3가지 핵심 기법: **Slow/Fast 포인터** → **In-place Reverse** → **Two Pointer 비교**. 이 3가지는 연결 리스트 문제의 기본 도구상자.

## 📊 복잡도

연결 리스트의 노드 수를 N이라 하자.

- **시간복잡도 O(N)** :
  - while 순회하며 `append` : O(N)
  - `vals[::-1]` 뒤집기 : O(N)
  - `==` 비교 (최악) : O(N)
  - → O(N)
- **공간복잡도 O(N)** :
  - `vals` 리스트 : O(N) (노드 값 N개 복사)
  - `vals[::-1]` : O(N) (뒤집힌 리스트 추가 생성)
  - → O(N)

## 🔀 풀이 비교

| 방식 | 시간 | 공간 | 구현 난이도 | 가독성 |
|------|------|------|------------|--------|
| 배열 복사 + 슬라이싱 (현재 풀이) | O(N) | O(N) | ⭐ | ⭐⭐⭐⭐⭐ |
| Slow/Fast 포인터 + in-place reverse | O(N) | **O(1)** | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| 재귀(Recursion) | O(N) | O(N) (콜스택) | ⭐⭐⭐ | ⭐⭐⭐ |

→ 첫 풀이 / 빠른 통과: **배열 복사 방식**
→ 면접 대비 / Follow-up 대응: **Slow/Fast 포인터**
→ 재귀적 사고 연습: **Recursion 방식**

## 📌 재발 방지 & 다음에 적용할 점

- 연결 리스트 문제를 만나면 **"배열로 내려서 풀기"** 와 **"포인터 조작으로 풀기"** 두 가지 방식을 모두 고민하기.
- 단일 연결 리스트는 역방향 탐색이 불가능하다는 특성을 항상 염두에 두기 (이중 연결 리스트와 구분).
- **Slow/Fast 포인터** 패턴은 연결 리스트의 중간 찾기, 사이클 검출, 팰린드롬 판정 등 다양하게 응용 가능 → 이번 주 내로 구현 연습.
- LeetCode 연결 리스트 기본기 3종 세트 완성하기:
  - **206 (Reverse Linked List)**: in-place reverse 연습
  - **234 (Palindrome Linked List)**: 오늘 푼 문제 ✅
  - **876 (Middle of the Linked List)**: Slow/Fast 포인터 연습
  - → 206 + 876을 합치면 234의 O(1) 공간 풀이가 자연스럽게 완성됨.
- **다음 리팩토링 목표**: 234번을 Slow/Fast 포인터 방식으로 다시 풀어 두 풀이를 비교 정리하기.
