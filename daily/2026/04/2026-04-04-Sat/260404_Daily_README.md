## 🔥 트러블슈팅 | Trouble Shooting

### ❌ 문제 상황

- 처음에 풀이 방법 자체가 떠오르지 않아 AI에게 힌트 요청
- n - 1 - i 를 i + 1 로 잘못 이해해서 수정
- for~else 구조를 처음 접해서 동작 방식 이해하는 데 시간 소요
- 이중 for문 흐름(i=0일 때 j가 어떻게 흘러가는지)을 단계별로 직접 추적하며 이해

### 🔍 원인 분석
- for~else 구조를 처음 접해 break 유무에 따라 실행 흐름이 달라진다는 점을 이해하는 데 시간이 걸렸음

### ✅ 해결 방법

- 이중 for문으로 i 기준 오른쪽 가격들과 하나씩 비교
- prices[i] > prices[j] 조건으로 가격이 떨어진 순간 포착
- 버틴 기간 = j - i (떨어진 시점 - 시작 시점)
- 끝까지 안 떨어진 경우 for~else로 처리, 버틴 기간 = n - 1 - i

## 📊 복잡도

- 시간복잡도 O(N²) : 이중 for문
- 공간복잡도 O(N) : answer 배열 크기
