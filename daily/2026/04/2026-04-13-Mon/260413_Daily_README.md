## 💡 오늘의 핵심 인사이트
- 팰린드롬 판별은 **전처리 후 비교** 또는 **Two Pointers** 두 가지 방식으로 접근 가능하다.
- 파이썬의 `isalnum()`, `lower()`, 슬라이싱 `[::-1]`을 조합하면 전처리 로직을 간결하게 작성할 수 있다.
- 리스트 컴프리헨션 방식은 **간결성**(O(N) 공간)을, Two Pointers 방식은 **메모리 효율성**(O(1) 공간)을 제공하는 트레이드오프 관계다.
- 문제 분류가 `Two Pointers`로 되어 있으면, 공간복잡도 O(1)을 기대하는 의도가 있을 가능성이 높다.

## 📊 복잡도

문자열 s의 길이를 N이라 하자.

- **시간복잡도 O(N)** : 리스트 컴프리헨션 순회 O(N) + `cleaned[::-1]`로 뒤집기 O(N) + `==` 비교 최악 O(N) → O(N)
- **공간복잡도 O(N)** : 정제된 리스트 `cleaned`가 최대 N개의 문자를 저장하고, 뒤집힌 리스트 `cleaned[::-1]`도 추가로 N개를 저장하므로 N에 비례한다.

## 🔀 풀이 비교

| 방식 | 시간 | 공간 | 조기 종료 | 가독성 |

| 리스트 컴프리헨션 | O(N) | O(N) | 불가 | ⭐⭐⭐⭐⭐ |

→ 메모리 제약 환경: Two Pointers


## 📌 재발 방지
- `isalnum()`은 알파벳 + 숫자를 모두 영숫자로 판정하므로, "문자만" 필터링하려면 `isalpha()`를 써야 함에 주의.
- 슬라이싱 `[::-1]`은 **새 리스트를 복사 생성**하므로 공간 O(N)을 추가로 사용한다는 점 인식하기.
- LeetCode처럼 **코딩 면접용 플랫폼**에서는 같은 문제를 여러 방식(간결 풀이 ↔ 최적화 풀이)으로 풀어보고 트레이드오프를 정리하는 습관 들이기.
- 다음번에는 **Two Pointers 방식(공간 O(1))** 으로도 풀어보고 두 풀이를 비교 정리하기.
