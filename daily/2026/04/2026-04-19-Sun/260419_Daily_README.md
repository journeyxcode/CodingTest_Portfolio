## 💡 오늘의 핵심 인사이트

- 음수는 맨 앞에 `-` 부호가 있어 절대 팰린드롬이 될 수 없으므로 **조기 반환(early return)** 으로 불필요한 연산을 제거할 수 있다.
- 정수를 `str()`로 변환하면 팰린드롬 판별이 간단해지지만, **Follow-up은 "문자열 변환 없이 풀기"** 를 요구한다. 수학적으로 절반만 뒤집어 비교하면 O(1) 공간으로 해결 가능.
- 팰린드롬 시리즈(125 → 234 → 9)의 공통 패턴: **"원본을 뒤집어 비교"** → 간결 풀이는 O(N) 공간, 최적화 풀이는 O(1) 공간.
- 끝자리가 0인 양수(예: 10, 100)도 팰린드롬이 아님. 수학적 접근 시 `x % 10 == 0 and x != 0` 조건으로 처리.

## 📊 복잡도

정수 x의 자릿수를 N이라 하자. (N = log₁₀ x)

- **시간복잡도 O(N)**:
  - `str(x)` 변환 : O(N)
  - `[::-1]` 뒤집기 : O(N)
  - `int(reverse_num)` 변환 : O(N)
  - `==` 비교 : O(1)
  - → O(N)

- **공간복잡도 O(N)**:
  - `str(x)` 문자열 : O(N)
  - `reverse_num` 문자열 : O(N)
  - → O(N)
