## 💡 오늘의 핵심 인사이트

- 이분탐색은 "값을 찾는 것"이 아니라 **"정답 후보값을 좁혀가는 것"** 이다
- 구하려는 답 자체를 `mid`로 놓는 것이 Parametric Search(매개변수탐색)의 핵심
- `lo`, `hi`는 사람이 설정하고, `mid`는 항상 `(lo + hi) // 2` 로 자동 계산된다
- 판별 함수는 **"mid를 정답으로 가정했을 때 가능한가?"** 를 True/False로 반환한다
- 최댓값을 구할 때는 가능해도 멈추지 않고 `lo = mid + 1`로 계속 탐색한다
- `lo > hi` 가 되는 순간 탐색 종료, 마지막으로 저장된 `answer`가 최종 정답이다
- 문제에서 **"가능한 한 최대/최소"**, **"~인 경우에는"** 문장이 보이면 이분탐색 신호

## 🔀 풀이 비교

| 구분 | 쉬운 버전 | 대안 1 (판별 함수 분리) |
|------|-----------|------------------------|
| 구조 | 로직을 while문 안에 직접 작성 | is_possible() 함수로 판별 로직 분리 |
| 가독성 | 보통 | 높음 |
| 성능 | 동일 | 동일 |
| 추천 상황 | 빠르게 구현할 때 | 코드 재사용, 유지보수가 필요할 때 |

```python
# 쉬운 버전 핵심
allocated = sum(min(b, mid) for b in budgets)
if allocated <= total:
    answer = mid
    lo = mid + 1

# 대안 1 핵심
def is_possible(mid, budgets, total):
    return sum(min(b, mid) for b in budgets) <= total
```
