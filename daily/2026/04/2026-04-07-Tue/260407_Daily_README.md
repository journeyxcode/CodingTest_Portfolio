## 📊 복잡도

- **시간복잡도 O(N)** : `str(n)` 변환, `[::-1]` 뒤집기, 리스트 컴프리헨션의 `int` 변환이 각각 O(N)으로 순차 실행된다. → O(N) + O(N) + O(N) = O(N)
- **공간복잡도 O(N)** : 변환된 문자열, 뒤집힌 문자열, 최종 반환 리스트가 각각 자릿수 N에 비례하는 메모리를 사용한다.

## 🔄 개선 과정

### v1. 인덱스 기반 접근

```python
def solution(n):
    size = len(str(n))
    answer = [0] * size
    
    stack = list(str(n))[::-1]
    answer = [int(stack[idx]) for idx in range(0, size, 1)]
    return answer
```

- 불필요한 중간 변수(`size`, `answer`, `stack`) 존재
- `str(n)`을 두 번 호출 (`len(str(n))`, `list(str(n))`)
- `[0] * size`로 초기화한 리스트가 바로 다음 줄에서 덮어씌워져 의미 없음

### v2. 리스트 컴프리헨션 간결화 

- 중간 변수 제거, `str(n)` 1회만 호출
- 문자열을 직접 순회하여 가독성 향상
