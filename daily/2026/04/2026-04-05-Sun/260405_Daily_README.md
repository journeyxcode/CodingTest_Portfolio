## 💡 오늘의 핵심 인사이트
- 스택에 값이 아닌 인덱스를 저장하면 answer[idx]로 정답 위치에 바로 접근할 수 있다
- answer = [-1] * size 로 초기화하면 오큰수 없는 경우의 기본값 처리와 인덱스 접근을 동시에 해결할 수 있다

---

## 🔥 트러블슈팅 | Trouble Shooting

### ❌ 문제 상황

- 이중 for문(O(N²))으로 먼저 시도했으나 시간초과 발생
- answer = [] 빈 리스트에 인덱스로 접근해 IndexError 발생


### 🔍 원인 분석

- answer = [] 로 초기화하면 인덱스로 직접 접근이 불가능하다는 점을 인지하지 못했음
- 이중 for문이 O(N²)으로 N이 1,000,000일 때 시간초과가 발생한다는 점을 몰랐음

### ✅ 해결 방법

- answer = [-1] * size 로 미리 초기화하여 IndexError 해결
- 이중 for문 → 스택 O(N) 풀이로 변경하여 시간초과 해결

## 📊 복잡도

- 시간복잡도 O(N) : 모든 원소가 스택에 최대 1번 push, 1번 pop
- 공간복잡도 O(N) : 수열 길이에 비례

## 📌 재발 방지

- 리스트에 인덱스로 접근할 때는 반드시 미리 초기화 여부 확인하기
- N이 큰 문제에서 이중 for문 대신 스택 O(N) 풀이 우선 고려하기
