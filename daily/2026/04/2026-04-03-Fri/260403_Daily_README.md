## 🔥 트러블슈팅 | Trouble Shooting

### ❌ 문제 상황

- "("와 ")" 비교하며 문제를 풀이 방법을 떠올리지 못함
- AI에게 문제를 접근할 수 있는 방법을 요청했고, for문 활용 방식 결정 

### 🔍 원인 분석

- 스택 자료구조를 괄호 짝 맞추기에 활용하는 패턴을 아직 경험하지 못했음

### ✅ 해결 방법

- result[]에 char가 "("이 오면 무조건 저장
- result[]에 "("가 top인 저장된 상태에서 ")" 값이 오면 -> "("을 pop() 실행
- for문 안에서 result[]의 len이 0이면 False로 리턴 

## 📊 복잡도

- 시간복잡도 O(N) : s의 길이 N 만큼 순회하고 내부 연산 모두 O(1)
- 공간복잡도 O(N) : 입력 배열 길이에 비례

## 📌 재발 방지

- 스택 push/pop 패턴 문제를 더 풀어서 유형에 익숙해지기
